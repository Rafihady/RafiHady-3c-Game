# 3C Programming | Fatman Journey
Proyek ini merupakan proyek yang diberikan untuk peserta Agate Game Course batch 9. Dalam game ini saya menerapkan konsep 3C pada game programming, dengan menerapkan banyak aksi untuk player seperti punch, gliding, climbing, crouch. Selain itu juga dalam projek ini saya menambahkan sedikit fitur Ai enemy sebagai tantangan terakhir pada stage.

<img width="1920" height="1200" alt="Screenshot (766)" src="https://github.com/user-attachments/assets/e0809b15-d85c-42be-a131-dcd532fd69be" />

# 🎮 Fitur Utama
* **Enemy_AI:** Membuat sebuah prefabs musuh yang bisa menyerang tapi hanya akan menyerang player di area tertentu.
* **Character:** Menmbuat character yang bisa menyerang musuh dan melakukan banyak fitur gerakan, selain itu menerapkan sistem Health Point pada character.
* **Camera System:** Menerapkan dua mode camera yaitu FPS dan TPS.
